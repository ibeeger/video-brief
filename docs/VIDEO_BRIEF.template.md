# 视频 Brief 模板

> 用途：给 AI agent（Claude Code / Cursor / Codex 等）下达视频制作任务的标准化说明书。
> 用法：复制本文件为 `BRIEF.md` 放进项目根目录，填完后告诉 agent「按 BRIEF.md 制作」。

---

## 填写前必读：一条心法

**形容词不可执行，参数才可执行。**

agent 无法把「高级感」「现代」「有冲击力」翻译成 CSS。它只能翻译成它训练数据里最平庸的那一版。

| ❌ 不可执行 | ✅ 可执行 |
|---|---|
| 现代简约风 | 深色底 `#0B0F14`，单一强调色 `#4ADE80`，无衬线粗体标题，正文 60% 白 |
| 节奏明快 | 每个场景 3–4 秒，转场 0.4 秒，字卡停留不超过 2 秒 |
| 动效自然 | 只用位移 + 透明度，缓动统一 `power2.out`，禁止旋转和弹跳 |
| 信息层级清晰 | 每屏最多 1 个标题 + 3 个要点，同屏文字不超过 40 字 |

**凡是你写下的形容词，都要在后面跟一个括号，把它翻译成数值、颜色码或明确的动作。** 这是这份 brief 里唯一真正决定成片质量的规则。

# 附：风格预设 · Apple 式克制

> **用法**：整段替换第 4 节。或告诉 agent「第 4 节采用 Apple 式克制预设」。

## 原则

**高级感不来自加东西，来自减东西、放慢、留白。**

绝大多数"做不出苹果感"的原因只有三个：元素太多、动效太快、字重太粗。这套预设的每一条本质都在对付这三件事。

---

## P.1 色彩

| 角色 | 值 | 说明 |
|---|---|---|
| 背景 | `#000000` | 真黑。不要用 `#111` `#1a1a1a` 这类"柔和黑"，那是网页安全色思维 |
| 次级背景 | `#1D1D1F` | 卡片、分区块 |
| 主文字 | `rgba(255,255,255,0.92)` | **不要纯白**。纯白在黑底上会晕开、显廉价 |
| 次文字 | `rgba(255,255,255,0.56)` | |
| 三级文字 | `rgba(255,255,255,0.36)` | |
| 强调色 | `#0071E3` | 全片**只用一个**强调色 |
| 分隔线 | `rgba(255,255,255,0.08)` | 1px，几乎看不见就对了 |

**规则**
- 强调色全片出现不超过 3 次，每次只用在一个元素上
- 禁止彩色渐变。需要渐变时只能是同色系极低对比（`#1D1D1F → #000000`）
- 无彩色占画面 95% 以上

---

## P.2 字体

### ⚠️ 许可提醒（重要）

**SF Pro 和苹方（PingFang）不能用于视频内容。** SF Pro 的许可仅限为 Apple 平台开发 App 的界面使用，苹方随系统分发同样受限。做商用视频用它们有风险。

**可放心使用的替代：**

| 用途 | 首选 | 备选 |
|---|---|---|
| 西文 | **Inter**（SIL OFL，几何形态最接近 SF Pro） | Geist、Instrument Sans、Helvetica Now（商业授权） |
| 中文 | **思源黑体 / Noto Sans SC**（SIL OFL） | HarmonyOS Sans（免费商用）、得意黑（标题） |
| 数字 | **JetBrains Mono** 或 Inter 的 tabular 变体 | 必须开等宽数字，否则跳动时会抖 |

### 参数

```
标题     Inter SemiBold(600) / 思源黑体 Medium
         字号 88–120px  行高 1.05  字距 -0.025em
副标题   Inter Regular(400)
         字号 36–44px   行高 1.35  字距 -0.01em
正文     Inter Regular(400)
         字号 28–32px   行高 1.5   字距 0
数字     tabular-nums 必开
```

**规则**
- **标题最重只到 SemiBold(600)。** 用 Bold/Black 堆标题是"苹果感"最常见的死因
- 字距必须为负。大字号不收字距，立刻变廉价
- 全片字号档位不超过 4 个
- 中文字距不要设负值（中文字形本身已满框，负字距会粘连）

---

## P.3 版式与留白

**留白是这套风格 80% 的来源。**

```
画布 1920×1080
左右安全边距   240px   （12.5%，是常规做法的 2 倍）
上下安全边距   160px
栅格           8pt grid，所有间距为 8 的倍数
常用大间距     64 / 96 / 128 / 160
```

**规则**
- **每屏最多 2 个信息元素**（一个标题 + 一行副标题就够了）
- 单屏文字总量不超过 30 字
- 大量内容宁可拆成更多场景，也不要挤在一屏
- 主体元素垂直居中或位于视觉上三分位，左对齐或居中，全片统一

---

## P.4 动效

这是最容易做错的一节。**慢 = 贵。**

```
缓动        cubic-bezier(0.28, 0.11, 0.32, 1)    全片统一，无例外
入场时长    0.8s – 1.2s                          不是 0.3s
位移距离    translateY(24px) → 0                 不超过 40px
缩放范围    0.98 → 1                             绝不超过 1.05
stagger     0.06 – 0.1s
```

**只允许两种入场**：淡入、淡入 + 微小上移。就这两种。

**绝对禁止**
- 弹跳、回弹（`back` / `elastic` / `bounce` 系缓动）
- 旋转、3D 翻转、透视
- 位移超过 40px 的"飞入"
- 缩放超过 1.05 的"爆出"
- 同屏超过 3 个元素同时运动

---

## P.5 转场

```
类型    交叉淡化（crossfade）
时长    0.6 – 0.8s
```

全片只用这一种。不用 shader，不用擦除，不用推移。花哨转场和这套风格是互斥的。

---

## P.6 材质（谨慎使用）

```
毛玻璃    backdrop-filter: blur(24px) saturate(180%)
          background: rgba(255,255,255,0.06)
边框      1px solid rgba(255,255,255,0.08)
圆角      20px（小卡片）/ 28px（大面板）
阴影      0 24px 64px rgba(0,0,0,0.4)     大范围、低透明、无锐边
```

一条片子里用毛玻璃的元素不超过 2 个。它是重音符号，不是背景纹理。

---

## P.7 节奏

**这一节比视觉参数更决定"高级感"。**

```
单场景停留      4 – 6 秒        （常规做法是 2–3 秒）
静止时刻        每个场景元素入场完成后，保持 1.5–2 秒完全静止
开场留白        首帧后 0.5 秒黑场再进内容
结尾留白        最后一个元素退场后 1 秒黑场
```

**画面上什么都不发生的时间，要占全片 30% 以上。** 这是苹果视频和普通视频最大的体感差异——不是它做了什么，是它敢什么都不做。

节奏上的直接后果：**同样的信息量，这套风格需要的时长比常规风格多 40%。** 定第 3 节的时长时要预留出来，否则一定会被迫加快节奏，然后前面所有参数都白设。

---

## P.8 禁止清单

给 agent 的负面约束，比正面描述有效：

- ❌ 纯白文字
- ❌ Bold 以上字重的标题
- ❌ 两个及以上强调色
- ❌ 彩色渐变背景
- ❌ 文字投影 / 描边（字幕的功能性描边除外）
- ❌ 装饰性几何图形、飞舞的粒子、光效扫光
- ❌ 弹跳缓动
- ❌ 0.5 秒以内的入场动画
- ❌ 快切、闪切、硬切
- ❌ 一屏超过 3 个元素
- ❌ emoji

# 附：填写示例（数据驱动型）

**0. 元信息**｜项目名：2025 中国咖啡市场增长解析｜系列：数据看行业 EP.12

**1. 产出目标**｜让观众记住「三四线城市增速是一线的 2.4 倍」这一个数字。成功标志：评论区出现对下沉市场的讨论。这不是消费指南，不推荐品牌。

**2. 受众**｜关注商业分析的 25–35 岁人群；懂 CAGR、渗透率这类词，不需要解释；主要在手机上静音刷到，**因此全片信息必须靠字幕和画面独立成立**。

**3. 规格**｜75 秒 / 16:9 / 1920×1080 / 30fps / mp4 / high / B站

**4. 视觉方向**
- 色彩：背景 `#0F1115`；强调色 `#E4572E`（仅用于关键数字，全片不超过 3 处）；主文字 `#F5F5F5`，次文字 `rgba(245,245,245,0.55)`；禁用蓝色系（与上一期重复）
- 字体：标题思源黑体 Heavy 72–96px；正文思源黑体 Regular 32px；数字 JetBrains Mono Bold（等宽，避免跳动时抖动）
- 版式：安全边距 120px；每屏最多 1 标题 + 3 要点；左对齐
- 动效：只用 Y 轴位移（≤40px）+ 透明度；禁止旋转、弹跳、3D 翻转；缓动统一 `power2.out`；单次 0.5s；多元素 stagger 0.08s
- 转场：CSS 模糊叠化，0.4s，全片统一
- 风格锚点：参考 Bloomberg 图表视频的**节奏和留白**，不要学它的配色

**5. 场景清单**

| # | 场景 | 时长 | 画面 | 字卡 | 数据 |
|---|---|---|---|---|---|
| 1 | 钩子 | 5s | 黑场中单个数字放大 | 「2.4 倍」 | — |
| 2 | 背景铺垫 | 12s | 全国市场规模柱状增长 | 三个要点逐条 | market.json |
| 3 | 核心对比 | 25s | 一线 vs 三四线双折线竞速 | 关键节点标注 | tier.json |
| 4 | 归因 | 20s | 三因素图解，逐个点亮 | 每因素一句 | — |
| 5 | 结尾 | 13s | 回到「2.4 倍」+ 订阅引导 | CTA | — |

必需场景：1、3、5｜可选可砍：4

**6. 配音**｜由 agent 依要点撰写，我确认后制作。语气：冷静克制，不煽动。TTS 音色 `zf_xiaobei`，语速 1.0。

**7. 字幕**｜必需。底部居中，48px，2px 黑描边无底板，每行≤15 字，整句出现。tts → transcribe 取时间戳。

**8. 音频**｜BGM：低调电子，-22dB；音效：仅数字跳动和转场；不做 audio-reactive。

**9. 数据源**｜`./data/market.json`、`./data/tier.json`。字段：`year`、`tier`、`value`、`yoy`。非批量。边界：`yoy` 为负时用灰色而非强调色；缺失年份留空不插值。

**10. 约束**｜不出现任何品牌 logo；不用「震惊」「碾压」类措辞；硬上限 80 秒；不嵌入实拍素材。

**11. 验收**｜lint / validate / inspect 全过；75±1 秒；snapshot 抽查 0:05、0:32、1:10；中文正常；`yuv420p`；数据与 json 逐项核对。
