# 形容词 → 可执行参数

Gate 2 的查表工具。

用法：在 BRIEF 里遇到形容词，查本表，把括号里的参数写到形容词后面。
**表里没有的、或有多种合理读法的，回问用户。不要挑一种默默写下去。**

写法示例：

> 节奏明快（每场景 3–4s，转场 0.4s，字卡停留 ≤2s）

---

## 质感类

| 形容词 | 它其实在说什么 | 可执行参数 |
|---|---|---|
| 高级 / 有质感 / 贵 | 元素少、动效慢、字重轻 | 每屏 ≤2 个信息元素；入场 0.8–1.2s；标题字重 ≤600；安全边距 ≥12.5% 画宽；静止时间占比 ≥30% |
| 精致 | 细节一致性 + 微弱层次 | 分隔线 1px `rgba(255,255,255,0.08)`；圆角统一一个值；阴影大范围低透明 `0 24px 64px rgba(0,0,0,0.4)`；间距全部为 8 的倍数 |
| 廉价（要避免的） | 纯白文字 + Bold 大字 + 满屏元素 | 反向约束：文字用 `rgba(255,255,255,0.92)` 不用 `#fff`；标题字重 ≤600；每屏 ≤3 元素 |
| 干净 / 简约 | 留白量 + 色彩数量 | 无彩色占画面 ≥95%；强调色全片 ≤3 次；每屏文字 ≤30 字；字号档位 ≤4 个 |
| 克制 | 不动 + 不加 | 只允许淡入、淡入+微小上移两种入场；单一强调色；禁装饰性图形 |
| 通透 | 深色底上的低不透明层次 | 卡片 `rgba(255,255,255,0.03)`；边框 `1px rgba(255,255,255,0.08)`；毛玻璃 `blur(20px) saturate(160%)`，全片 ≤2 处 |

## 节奏类

| 形容词 | 它其实在说什么 | 可执行参数 |
|---|---|---|
| 明快 | 单场景短 + 转场短 | 每场景 3–4s；转场 0.4s；字卡停留 ≤2s |
| 快 / 抓人 / 刷得住 | 信息点密度 | 每 1.2–1.8s 一个信息点；首 1.5s 必须给结论或冲突；硬切为主 |
| 舒缓 / 从容 | 单场景长 + 静止长 | 每场景 4–6s；元素入场完成后保持 1.5–2s 完全静止；开场 0.5s 黑场，结尾 1s 黑场 |
| 紧张 | 递减的场景时长 | 场景时长逐场递减（如 6s → 4s → 2.5s）；转场时长同步递减 |
| 有呼吸感 | 静止占比 | 画面上什么都不发生的时间 ≥全片 30% |

## 动效类

| 形容词 | 它其实在说什么 | 可执行参数 |
|---|---|---|
| 自然 / 顺 | 只用位移+透明度，缓动统一 | 只允许 `translateY` + `opacity`；缓动全片统一一条曲线；禁旋转、禁弹跳 |
| 丝滑 | 长时长 + 慢出缓动 | 入场 0.8–1.2s；`cubic-bezier(0.28, 0.11, 0.32, 1)`；位移 ≤40px |
| 有冲击力 | 尺度对比，不是速度 | 关键数字字号 ≥120px，其余 ≤32px；单屏只留一个元素；入场前先给 0.5s 黑场 |
| 活泼 / 有弹性 | 允许回弹（仅竖屏类风格） | `back.out(1.4)`；入场 0.3–0.4s；位移 ≤60px。**`apple-restraint` 下禁用** |
| 层层递进 | stagger | 多元素入场 stagger 0.06–0.1s；同屏同时运动的元素 ≤3 个 |
| 干净的转场 | 单一转场类型 | 全片只用一种转场；不混用 CSS 原语与 shader；时长统一 |

## 情绪 / 色彩类

| 形容词 | 它其实在说什么 | 可执行参数 |
|---|---|---|
| 冷静 / 客观 | 无彩色为主 + 单一强调色 | 无彩色 ≥95%；强调色 1 个，全片 ≤3 次；禁彩色渐变 |
| 温暖 | 强调色色相 | 强调色落在 20°–45° 色相（如 `#E4572E`、`#F97316`）；背景不动，仍为无彩色 |
| 科技感 | 深底 + 冷色光晕 + 等宽字 | 背景 `#08090A`；光晕 `radial-gradient` 冷色低透明；小字用等宽体；圆角 12/16px |
| 严肃 / 权威 | 字重 + 对齐 + 无动效花活 | 标题字重 700；全片左对齐；只用淡入；禁装饰图形 |
| 有活力 | 强调色饱和度 + 尺度 | 强调色饱和度 ≥80%；标题字重 ≥800；字号 ≥96px |
| 可信 | 数据可追溯 | 每个数字标注来源与口径；坐标轴从 0 起；负值用中性灰不用红 |

## 结构 / 信息类

| 形容词 | 它其实在说什么 | 可执行参数 |
|---|---|---|
| 层级清晰 | 每屏元素上限 + 字号档位 | 每屏 ≤1 标题 + ≤3 要点；同屏文字 ≤40 字；字号档位 ≤4 个 |
| 信息量大 | 拆场景，不是挤一屏 | 超出每屏上限就拆成更多场景；宁可加场景不加密度 |
| 重点突出 | 强调手段唯一 | 只用一种强调手段（颜色 或 字号 或 位置），不叠加 |
| 一目了然 | 首屏结论前置 | 结论放场景 1；论证放中段；不要把结论留到结尾 |

## 翻译不了的时候

以下形容词**没有稳定映射**，必须回问：

- 「有设计感」「大气」「国际化」「年轻化」「高端但不高冷」 —— 问：你能给一个参考链接或截图吗？参考它的什么（配色 / 节奏 / 版式）？明确不要学的是什么？
- 「像 XX 公司的片子」 —— 问：具体哪一支？参考它的哪一层？
- 「差不多就行」 —— 问：那这条视频发到哪里、给谁看？（回到 §2 §3）

回问时给用户具体选项，不要开放式发问。
